# Richard Mkandawire Personal Portfolio

## Project Overview

This project is a personal portfolio website designed to present my academic background, technical skills, creative work, and software development projects. The website serves as a digital identity for showcasing my work to potential employers, academic supervisors, clients, and collaborators. It was developed in accordance with the requirements of Assignment 2 for the Multimedia Tools and Their Application course.

The portfolio is built to communicate who I am, what skills I possess, the projects I have developed, and how interested parties can contact me. It also demonstrates practical use of HTML, CSS, and JavaScript in creating an engaging and professional user experience.

## Objectives

The main objectives of this project are to:

- create an online professional portfolio for personal branding
- present academic and professional information clearly and effectively
- showcase projects and technical capabilities
- demonstrate creative design and interactive web elements
- provide contact information and relevant links to social and professional profiles
- publish the website using GitHub Pages for online accessibility

## Website Sections

The portfolio includes the following sections:

- Home
- About Me
- Projects
- Animated Concepts
- Contact
- CV

Each section is linked through the navigation menu and is designed to create a positive first impression while maintaining a consistent visual identity throughout the website.

## Key Features

- Responsive multi-page layout for desktop, tablet, and mobile devices
- Professional homepage with a hero banner and call-to-action buttons

## How the Project Works

The portfolio is designed as a static website made up of separate HTML pages linked together by a shared stylesheet and JavaScript file. Each page has a distinct purpose:

- `index.html` loads the homepage and introduces the user to the portfolio with a hero section, branding, and navigation.
- `about.html` contains educational background, technical skills, interests, career goals, and contact information.
- `projects.html` displays major projects and provides direct links to live GitHub repositories.
- `animations.html` demonstrates the interactive and motion-based concepts implemented using CSS and JavaScript.
- `style.css` controls the layout, typography, colors, spacing, responsiveness, and visual presentation of the entire site.
- `script.js` enhances the site with dynamic interactions such as typing effects, reveal animations, and responsive navigation behavior.

Together, these components produce a complete, professional, and visually engaging portfolio website.

## Running the Website Locally

To run the portfolio locally, follow these steps:

1. Download or clone the repository to your local computer.
2. Open the project folder in Visual Studio Code.
3. Launch `index.html` in a browser to view the homepage.

Alternatively, a local static web server can be used to preview the site from the project directory.
